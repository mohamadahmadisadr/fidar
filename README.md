# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/20015513-4d83-47a9-92e9-f17cf028f227

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env.local` and fill in the Gemini and `VITE_FIREBASE_*` values from your project settings
3. Run the app:
   `npm run dev`
